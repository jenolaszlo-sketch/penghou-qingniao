# Security

Penghou.Qingniao is pre-release software. Do not treat its current APIs as a
complete security boundary.

Qingniao validates delegation policy and normalizes execution evidence, but the
host remains responsible for authenticating callers, authorizing workspaces and
providers, isolating execution, protecting credentials, limiting resources,
redacting sensitive data, and verifying external artifacts.

Please report suspected vulnerabilities privately through the security
reporting facilities of the repository rather than opening a public issue.
